# MANUAL DE CONFIGURARE FINALĂ - CV Builder PRO ATS

Proiectul tău a fost optimizat și securizat la maximum. Eu, asistentul tău, am scris tot codul, iar ție îți rămân de parcurs doar pașii administrativi și configurarea cheilor secrete. 

Urmează ACEȘTI PAȘI în ordinea listată:

---

## PASUL 1: SETAREA FIREBASE (Baza de Date & Găzduire)
1. Mergi la https://console.firebase.google.com/ și creează un proiect nou (ex: "CV Builder ATS").
2. În panoul din stânga, apasă pe **Build -> Authentication** și dă "Get Started". Mergi la secțiunea "Sign-in method" și activează **Google**.
3. În panoul din stânga, apasă pe **Build -> Firestore Database** și creează baza de date (alege locația Europa, modul "Production mode"). Mergi la tab-ul "Rules" (Reguli) și pune această regulă de siguranță pentru a permite scrierea și citirea profilurilor doar backend-ului tău și utilizatorilor:
   `allow read, write: if request.auth != null;` (Pentru început poți pune `allow read, write: if true;` până testezi totul, apoi o schimbi).
4. Pe pagina principală a proiectului Firebase (rotița din stânga sus -> Project Settings), la secțiunea "Your apps", alege iconița Web `</>` și înregistrează aplicația. 
5. Copiază obiectul de configurare `firebaseConfig` (Acel cod cu apiKey, authDomain, etc.).
6. Deschide fișierul `public/app.js` de pe calculatorul tău, du-te la Linia 11 și **Înlocuiește structura FIREBASE_CONFIG cu datele tale abia copiate**.

---

## PASUL 2: SETAREA STRIPE (Plăți)
1. Mergi la https://dashboard.stripe.com/ (creează cont / loghează-te).
2. Pe bara de sus (în modul TestMode - colțul dreapta sus) apasă pe **Developers -> API keys**.
   - Acolo vei găsi cheia Secretă (`sk_test_...` sau `sk_live_...`). 
   - Copiază această cheie Secretă, deschide fișierul `functions/index.js` și lipește-o la linia 3, înlocuind cuvântul `SK_TEST_INLOCUIESTE_CU_CHEIA_STRIPE`.
3. Mergi în stânga la **Product Catalog** și vom crea 2 produse:
   - **PRODUS 1 (Abonament Lunar):** Adaugă produs nou, numește-l "CV PRO - Abonament Lunar". Pune prețul de 5 EUR (Recurring/Lunar).
   - **PRODUS 2 (Plată Unică):** Adaugă alt produs nou, numește-l "CV PRO - 1 Export Fără Watermark". Pune prețul de 3 EUR (One-Time/O singură dată).
4. Creează câte un **Payment Link** pentru fiecare produs:
   - La ambele, bifează "Don't show confirmation page", ci dă redirect către viitorul tău domeniu, adăugând parametrul: `https://DOMENIULTAU.ro/?session_id={CHECKOUT_SESSION_ID}`
5. Deschide fișierul `public/app.js` (Liniile 28-29) și:
   - Înlocuiește `LIPESTE_STRIPE_LINK_5_EUR_LUNAR_AICI` cu link-ul de plată pentru produsul 1.
   - Înlocuiește `LIPESTE_STRIPE_LINK_3_EUR_UNIC_AICI` cu link-ul de plată pentru produsul 2.

---

## PASUL 3: CONFIGURAREA WEBHOOK-URILOR (Securitate)
1. Tot în Stripe, la **Developers -> Webhooks**, adaugă un Endpoint nou.
   - Endpoint URL-ul îl vei avea abia DUPĂ ce urci funcțiile Firebase pe server. Îl vom pune imediat.
   - La Evenimentele pe care trebuie să le asculte bifează **checkout.session.completed**.
2. După ce ai creat Webhook-ul, Stripe îți dă un "Signing Secret" (începe cu `whsec_...`).
   - Copiază-l, deschide `functions/index.js` și lipește-l la Linia 13, înlocuind cuvântul `WHSEC_INLOCUIESTE_CU_CHEIA_WEBHOOK`.

---

## PASUL 4: DEPLOY (Urcarea pe internet)
1. Deschide terminalul din calculatorul tău (în folderul proiectului `Model CV PRO ATS`).
2. Rulează comenzile:
   ```bash
   npm install -g firebase-tools
   firebase login
   firebase init
   ```
   (Alege Hosting și Functions. La Functions alege JavaScript. Când te întreabă de suprascriere, dă NO la index.html și index.js ca să nu ștergi munca mea).
3. Intră în folderul funcțiilor pentru a instala pachetele necesare:
   ```bash
   cd functions
   npm install
   cd ..
   ```
4. Rulează comanda supremă care urcă totul pe internet:
   ```bash
   firebase deploy
   ```

## PASUL FINAL
1. După finalizarea comenzii de deploy, Firebase îți va afișa în terminal niște link-uri verzi (Function URL). Unul dintre ele este pentru **generatePDF** și unul pentru **stripeWebhook**.
2. Copiază linkul funcției `stripeWebhook` și pune-l în Stripe la pasul 3.1.
3. Copiază linkul funcției `generatePDF`, deschide fișierul `public/app.js` și lipește-l la linia 33 în locul variabilei `CLOUD_FUNCTION_URL`.
4. Urcă modificările finale relansând: `firebase deploy --only hosting`.

Gata! Platforma ta este online, securizată impecabil și funcțională cap-coadă! Succes la vânzări!
